API reference

The data contract and fixed-effects path are the starting point. A method being documented does not establish qualification of all inherited effect or inference combinations; read tested scope.

CJSModels.CJSModels — Module

Experimental first-capture-conditional Cormack-Jolly-Seber models.

CJSModels.CJSFit — Type
CJSFit

Maximum-likelihood CJS result. Contains process-labelled coefficients, training schemas/contrasts, offsets, log likelihood, curvature, optimizer attempts and identification/boundary diagnostics. A converged fit alone is not evidence that uncertainty is calibrated.

CJSModels.CMRData — Type
CMRData(Y; ids, occasions, units, observed=nothing, intervals=nothing,
        ends=nothing, frequency=nothing, phi_data=nothing, p_data=nothing)

Validated first-capture-conditional capture histories. Rows are individuals; columns are occasions. ends is administrative follow-up, never last sighting. observed=false omits an emission while retaining survival transitions. frequency contains positive integer replication counts, not arbitrary weights.

Predictor tables are keyed by id, interval_start, interval_end (survival) and id, occasion (detection). Survival requires every post-capture interval; detection requires only surveyed post-capture occasions. Earlier and unsurveyed detection rows are optional. Input row order is ignored. intervals uses the declared units; otherwise numeric occasion differences are used. Missing encounters require an explicit false observation mask.

CJSModels.cjs — Method
cjs(data::CMRData; phi=@formula(phi~1), p=@formula(p~1),
    terminal_constraint=nothing, sd_phi=nothing, sd_p=nothing,
    selection=nothing, start=nothing, maxiters=1000, g_tol=1e-8)

Fit first-capture-conditional CJS by ML. Survival coefficients model logit unit-time apparent survival; interval survival is s^Delta. Detection coefficients model logit capture probability conditional on alive. LHS symbols phi/p are labels, never response columns. offset(x) is a fixed link-scale contribution. Training schemas, contrasts and levels are kept.

Unrestricted terminal time-specific survival/detection requires an explicit terminal_constraint=(phi=value,) or (p=value,), fixing one final unit-time survival or detection probability globally. Constrained flat directions are removed. One shared Gaussian intercept (1 | group) per process uses the joint CJS Laplace approximation. Shared effects are independent across processes; their conditional Hessian retains all cross-process and cross-year entries. Persistent individual intercepts (1 | id) use normalized Gaussian quadrature over each full history. sd_phi and sd_p optionally give process-specific formulas for log SD; predictors must be constant within the individual or shared grouping unit. Shared SD formulas use unit-specific scales in the joint Laplace objective. Orders 25, 41, 65 and 97 are fixed within each optimizer run and refined between fits. selection=(eligibility=indices, assumption=:alive_available) applies an individual first-capture correction, requiring each random effect to be grouped by id, complete prehistory predictors, and shared pre/post coefficients. It conditions on the realized first-capture occasion. Shared-effect selection, random slopes, and shared-plus-individual effects remain unavailable. Ordinary shared and unselected individual effects support explicit prediction targets and persistent-draw simulation. Selected individual effects support response-scale selected-cohort prediction and rejection-sampled simulation for the fitted capture layout. Prediction accepts new selected profiles only when eligibility, first capture, complete prehistory, survey masks, and covariates are supplied explicitly. Shared SD formulas retain guarded prediction/simulation. Heterogeneity uncertainty remains unqualified. ML is the sole likelihood target.

CJSModels.offset — Method

A known additive predictor term on the linear-predictor scale.

CJSModels.simulate — Method

Simulate fresh first-capture-conditional marked-cohort histories with fitted parameters held fixed. Every expanded frequency copy receives fresh independent normal effects for active processes, persistent over its whole history. First capture, survey masks, administrative ends, keyed predictors and units remain fixed. Returns Vector{CMRData} suitable for refitting. This is not simulation from existing individuals' posterior effects or a full population model. An explicit seed leaves the caller RNG unchanged. Individual SD formulas draw from the fitted SD for each supplied training profile. Reference-selection fits simulate from the reference law and reject draws until each fitted first- capture time is realized. The max_selection_attempts keyword bounds attempts per individual. Ordinary shared fits draw one effect per group and process for each replicate. Individual confidence intervals remain guarded.

StatsAPI.confint — Method

CJS uncertainty summaries with explicit availability status.

Native shared-effect method=:profile constrains fitted fixed and log-SD coefficients and reoptimizes nuisance parameters using the joint CJS Laplace objective. Interior constant-SD targets exponentiate finite log-SD profile endpoints; SD-formula targets are coefficients on the log-SD scale. Boundary fits and exact-zero SD limits remain guarded. Returned shared profiles have calibrated=false; numerical availability does not establish interval coverage.

StatsAPI.predict — Method

Predict CJS processes on keyed rows, preserving fitted schemas, offsets and units. Ordinary persistent individual fits require target=:zero_effect (latent effects set to zero) or target=:integrated (response probabilities averaged over the fitted marked-cohort normal law). Interval survival averages s^Delta directly. The parameters are held fixed. These are supplied-profile process averages, not history-conditioned effects or later-survivor averages. Integrated link prediction remains unsupported. For a fitted reference-selection individual model, target=:reference_selected returns response-scale process means under the first-capture-weighted reference effect law and does not condition on later histories. Fitted IDs reuse their fitted SD profiles. New IDs require an explicit selection profile containing the eligibility index, first-capture index, complete prehistory interval rows, and survey mask/captures. SD-formula predictors must be supplied consistently in the prehistory and future process tables. This predicts supplied profiles; a population average still requires a declared reference covariate distribution. Ordinary shared fits use fresh reference-group means with the same explicit targets.
